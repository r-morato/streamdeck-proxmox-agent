# Stream Deck Neo — 10" 1U Rack Mount

A 3D-printable mount that holds an [Elgato Stream Deck Neo](https://www.elgato.com/) in a 10" 1U rack, based on the [10" 1U Server Rack Template](https://www.printables.com/model/697999-10-1u-server-rack-template) by its original author on Printables.

## What's different from the original

- Added a gap in the base to fit the Stream Deck Neo's shape/feet.
- Added a cable gap/cutout to route the USB cable out the back cleanly.

## Files

| File | Description |
|---|---|
| `*.f3d` | Fusion 360 source file|
| `*.stl` | Print-ready mesh export|
| `*.3mf` | Print-ready export|

- No supports required.
- Standard 1U rack width/height per the original template; only the base and cable cutouts were modified.
